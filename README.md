# ローマ字ガンマン

ひらがなを見てローマ字を思い出す、キーボード用のタイピングゲームです。

- 練習モードは行を選んで30文字。時間制限はありません。
- 本番モードはゾンビは１体ずつ。１体につき20秒、５体でクリア。20種類の敵から毎回５体が登場します。
- ヒントはキーボード上に次のキーを表示します。表示中は本番の計時が止まり、ひらがな一文字分を打つと閉じます。
- 音量・消音と出題モードの選択は、このブラウザーに保存されます。

GitHub Pages で遊べます。手元では、このフォルダーの index.html をブラウザーで開いて遊べます。ビルドやアカウント登録は不要です。
